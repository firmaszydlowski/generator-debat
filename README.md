# Generator debat

Debaty „za i przeciw” dla szkół: wybór tematu, ściąga i debriefing dla prowadzącego, głosowanie z telefonów, timer i widok na telewizor.

- `index.html`: nauczyciel (wymaga kodu szkoły)
- `p.html`: prowadzący (link z kluczem sesji)
- `u.html`: uczniowie
- `tv.html`: telewizor

Strony są budowane automatycznie. Nie edytuj ich ręcznie.
